# 晴天 · 花序唱片｜声音植物志

一个单文件的交互式页面：把歌词里那朵小黄花夹在纸上，几年后再取出来，才发现花心是一面可以重听的唱片。

花瓣是手刻版画式的程序绘图。花心从外到内走九圈，每圈一段，恰有 1,243 道音痕。同一枚音符决定音沟的位置、深浅和长度，也触发一根有泛音、木质共鸣与短促金属触音的虚拟琴弦。五线谱以 G 大调、4/4、四分音符每分钟 68 拍记谱，简谱标 67。
